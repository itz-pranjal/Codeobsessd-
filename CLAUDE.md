## Project: CodeObsessed
A documentation-style blog for beginner and intermediate programmers.
Built with Astro. Articles are Markdown files. No backend, no database.

## Stack
- Framework: Astro (static)
- Styling: Vanilla CSS inside .astro files
- Content: Markdown files in src/content/articles/
- Deploy: Netlify via GitHub

## Folder Structure
- src/components/  — reusable UI blocks
- src/layouts/     — page templates (BaseLayout, ArticleLayout)
- src/pages/       — routes
- src/content/articles/ — all article .md files

## Rules
- No TypeScript
- No CSS frameworks
- No npm packages beyond Astro core
- Adding a new .md file to src/content/articles/
  is all that is needed to publish a new article

## Article Frontmatter Fields
title, description, difficulty, date, related, coverImage

## Design Theme
Documentation style. Dark background. Monospace headings.
One accent color: muted blue (#3b82f6). Max width 720px.
